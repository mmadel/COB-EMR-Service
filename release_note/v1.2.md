# Release Notes — COB EMR Service v1.2

## Overview

Initial release of the COB EMR (Electronic Medical Records) Service — a comprehensive backend platform for managing clinical operations, patient records, scheduling, and medical documentation.

## Key Features

### Organization & Clinic Management
- Multi-organization support with clinic creation, editing, and deletion
- Referring provider management per organization
- Organization signup workflow with administrator provisioning

### User Management
- Clinical and clerical user roles with Keycloak-based authentication
- Role-based access control and permission assignment
- User creation, update, deactivation, and clinic assignment

### Patient Management
- Full patient lifecycle: registration, chart management, and clinic linking
- Patient cases with insurance associations and authorization tracking
- Patient case authorization with automatic visit counting and date-of-service tracking

### Scheduling & Calendar System
- Multi-calendar support with clinic attachment and user-level visibility settings
- Appointment creation with daily, weekly, monthly, and yearly recurrence
- Appointment series management, status tracking (check-in, check-out, no-show, cancel)
- Appointment types with customizable colors
- Scheduler configuration per clinic (start/end times)
- Cancellation fee and payment record tracking

### SOAP-Based Medical Documentation
- Configurable SOAP fields organized by section, category, and medical note type
- Support for four note types: Initial Examination, Daily Note, Progress Note, and Discharge Note (quick and full)
- Draft, finalize, forward, and delete workflows for all note types
- Automatic field population and reset logic across note types (e.g., assessment/diagnosis reset on daily note creation)
- Objective profiles for organizing clinical measurements

### OMT Testing & Scoring
- Built-in scoring engines for orthopedic measurement tests: UEQD, SPADI, DASH, UEFI, FAAM, HOOS/KOOS, NDI, Oswestry, and balance tests
- API-driven test value persistence and score calculation

### Initial Examination Summary
- Automated summary generation from finalized initial exam notes covering subjective (pain, prior/current function, medical history), objective (scores), assessment, and plan of care

### Patient Records & Webhooks
- Paginated patient record views with per-line actions based on note status
- Domain event processing for note drafting, finalization, and diagnosis assignment
- Webhook integration for medical note and diagnosis events

### Billing Support
- Billing section models for timed/untimed codes across note types
- CPT code and ICD-10 diagnosis management
- Automatic code reset logic for progress and discharge notes

### Deployment & Infrastructure
- Jenkins CI/CD pipeline with health-check based deployment
- Environment-specific configuration for staging and production
- MySQL database backend
